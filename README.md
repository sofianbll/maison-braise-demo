# Maison Braise demonstration

A static fictional restaurant demonstration. The names, menu, prices, address and hours are illustrative. Ordering and contact actions are disabled. The food image is AI-generated and represents no actual restaurant.

Six pages, 24 menu items and six categories. No accounts, payment, email submission or analytics are configured. Google Fonts loads the body font; the legal page identifies the intended GitHub Pages hosting and links to the providers' information.

Run `node verify.mjs` before publication. For local preview, serve the directory over HTTP. A direct file opening can block menu JSON loading; the static menu remains available.

This directory is a prepared publication snapshot. Creating it does not create a GitHub repository, configure Pages or publish a website.
